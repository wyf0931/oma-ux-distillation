# Derived Principles

Principles are higher-level interpretations supported by multiple validated patterns. They remain hypotheses about why a set of interaction mechanisms may work; they are not direct observations or claims about measured user outcomes.

## Current principles

- [Preserve the Active Task Context](principles/preserve-active-task-context.md) — a medium-confidence synthesis supported by five patterns. Request-type routing and pre-query destination shortcuts define its scope boundaries.

Add a principle only when repeated pattern evidence supports a shared rationale and meaningful boundaries have been compared. Keep links to the supporting patterns in each record; do not create categories or token vocabulary to fill the taxonomy.
